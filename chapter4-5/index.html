3.1 · Overview of data visualization

Preattentive attributes: seen before you think

Cognitive load is the effort needed to process a visual accurately. Lower load means easier to read.
Preattentive attributes are features your brain picks up in under ~250 ms: colour, size, shape, length.
Colour is very effective, but too much distracts, and colour blindness can hide it.
Size: people struggle to compare 2-D areas. Length: best for quantities, because a longer bar means a bigger value.

3.1 · Data-ink ratio

Every drop of ink should earn its place

Data-ink ratio = ink used for data ÷ total ink in the table or chart.
Data-ink carries meaning. Non-data-ink (heavy borders, grids, shading, 3-D) adds nothing.
Decluttering raises the ratio. White space works the same way.
Tip: Excel's defaults add clutter. Clean them up before you present.

3.2 · Tables

Table, chart, or both?

Use a table when readers need to:

  • refer to specific numbers
  • make precise comparisons between values
  • see values with different units or very different magnitudes

3.2 · Table design

Which table is easiest to read? Vote, then reveal

Design rules

  • Use lines only to separate labels from data and totals from the rest.
  • Left-align text labels, right-align numbers so the digits line up.
  • Centre column group labels, such as Month.
  • Show negatives clearly, e.g. (3,980).

3.3 · A note on pie & 3-D charts

Pie challenge: who manages more, Francois or Lopez?

Decide from the pie alone. No peeking at the numbers!
Why pies struggle: they use size (angle and area), which is hard to compare, and colour coding that colour-blind readers can miss. 3-D charts distort size even more. Prefer a sorted bar chart.
3.3 · Column charts

Stacked or clustered? It depends on the question

NorthSouth

Stacked

Answers “What is the total each month, and what share is each region?” Only the bottom segment sits on a common baseline.

Clustered

Answers “How do North and South compare each month?” Often better, but cluttered with many series.

Try it: in which month does South overtake North? Which view shows it faster?

Horizontal versions are stacked-bar and clustered-bar charts. Excel: Insert ▸ Column or Bar Chart.

3.4 · Specialized data visualizations

Parallel coordinates: one line per observation

First base (1B)Second base (2B)
  • Used for data with more than two variables.
  • Each vertical axis is a variable: home runs (HR), stolen bases (SB), batting average (AVG).
  • Each line is one player. Its height on each axis is that player's value.
The textbook example: a 1B with 39 HR, 1 SB, .338 AVG and a 2B with 0 HR, 30 SB, .222 AVG. Look at the line slopes.

Extra players are made up for illustration, to show how groups form patterns. They are not textbook data.

3.5 · Visualizing geospatial data

Maps: choropleths and cartograms

Choropleth map: shades, colours or symbols on geographic areas show a value, e.g. a weather map of daily highs, or median income by state. Excel: Insert ▸ Maps ▸ Filled Map.
Cartogram: map regions are resized by a variable, e.g. population. Weakness: the distortion can make the geography unreadable.
Equal-area cartogram: every state gets the same tile, so small states don't vanish, but positions stay roughly true. Not available in Excel.
Think: Selangor vs Perlis on a normal map. Which one would your eye notice first, and is that fair?

Wrap-up

Which visual, when?

TableExact values, mixed units or magnitudes.
Scatter / bubbleRelationship between 2 (or 3) variables.
Line / sparklineChange over time.
Sorted barCompare categories. Better than a pie.
Stacked / clusteredTotals with parts / side-by-side comparison.
Heat mapSpot patterns across a big grid.
Treemap / waterfallHierarchies / build-up to a total.
Map / dashboardGeography / KPIs at a glance.
