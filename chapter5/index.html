5.2 · Basic relationships

Complement, union, intersection and the addition law

P(A)P(B)P(A∩B)
P(Aᶜ) = 1 − P(A)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Why subtract the intersection? Adding P(A) and P(B) counts the overlap twice. Mutually exclusive events have no overlap, so P(A ∪ B) = P(A) + P(B).

5.2 · Application of the addition law

50 workers: late, defective, or both?

Late onlyDefective onlyBothNeither

A manager checks the work of 50 workers: 5 finished late, 6 made defective products, and 2 did both. What is the probability that a worker is late or defective?

Common mistake: 5/50 + 6/50 = 0.22 counts the 2 "both" workers twice. The correct answer is 0.18.

5.3 · Independent events · multiplication law

Independent or not? And the multiplication law

Is default independent of marital status?

A and B are independent if P(A | B) = P(A). Knowing B does not change A.

Multiplication law: P(A ∩ B) = P(B) · P(A | B)
If independent: P(A ∩ B) = P(A) · P(B)

Mutually exclusive ≠ independent

5.3 · Bayes' theorem

Bayes' theorem: a bad part arrived. Which supplier?

S1 share Bad rate S1 S2
P(A₁ | B) = P(A₁)P(B | A₁) / P(B)
P(B) = P(A₁)P(B | A₁) + P(A₂)P(B | A₂)

Prior → new information (a bad part) → Bayes' theorem → posterior. Textbook default: 65% / 35% of parts; 2% / 5% bad.

5.4 · Random variables

Discrete or continuous? 0 / 8

A random variable is a numerical description of an experiment's outcome. Discrete = countable values (0, 1, 2, …). Continuous = any value in an interval.

Line-segment test: pick two possible values. If every point between them is also possible, the variable is continuous.
5.5 · Discrete probability distributions

Expected value, variance and SD of a discrete variable

Number of mortgage payments per year (x) for 300 customers. Change the counts and everything updates.

E(x) = μ = Σ x·f(x)
Var(x) = σ² = Σ (x − μ)²·f(x)
=SUMPRODUCT(A2:A4,B2:B4)

A valid distribution needs every f(x) ≥ 0 and Σ f(x) = 1. These are relative frequencies, so it is an empirical (custom) discrete distribution.

np

5.5 · Poisson probability distribution

Poisson: how many arrivals in an interval?

Mean μ (arrivals per hour)

Patients arriving at an emergency room average 10 per hour. The number of arrivals per hour is Poisson: occurrences in an interval (time, length, area), independent, with a constant average rate.

f(x) = μˣe^(−μ) / x!
=POISSON.DIST(x,μ,FALSE)

5.6 · Continuous probability distributions

Uniform distribution: probability is area

Fromto

Flight time from Chicago to New York is uniform between 120 and 140 minutes: every minute in the range is equally likely.

f(x) = 1/(b − a) for a ≤ x ≤ b
E(x) = (a + b)/2
Var(x) = (b − a)²/12
  • For continuous variables, P(x = exactly 130) = 0. We only find probabilities of intervals.
  • The total area under f(x) is always 1.
5.6 · Triangular probability distribution

Triangular: when you only know min, most likely, max

amb Interval

A project's assessment phase: experts say at least 6 months (a), most likely 12 (m), at most 24 (b). That is a subjective but practical model, common in project and simulation work.

P(x ≤ c) = (c − a)² / ((b − a)(m − a)) for c ≤ m
P(x ≤ c) = 1 − (b − c)² / ((b − a)(b − m)) for c > m

Check: with a = 6, m = 12, b = 24, P(10 ≤ x ≤ 18) = 0.8333 − 0.1481 = 0.6852. The pptx slide states 0.6111, which does not match these parameters.

5.6 · Normal probability distribution

Normal distribution: Grear aircraft engines

μσ
x

Engine lifetime (flight hours) is normal with μ = 36,500, σ = 5,000. What share of engines last 40,000+ hours?

=1-NORM.DIST(40000,36500,5000,TRUE)
  • μ moves the curve; σ makes it wider and flatter.
  • Symmetric: 0.5 on each side of μ. Tails never touch the axis.
5.6 · Finding a value for a probability

NORM.INV: set the warranty guarantee

% of engines eligible for discount

Grear will give a discount on a new engine if the old one fails before a guaranteed number of hours. Only 10% of engines should qualify. What guarantee should it offer?

=NORM.INV(0.1,36500,5000)
NORM.DIST: value → probability.
NORM.INV: probability → value.
5.6 · Exponential probability distribution

Exponential: time between events

Mean μ (months)Interval

The time between business-loan defaults at a bank is exponential with a mean of 15 months. What is the probability that the next gap is between 6 and 18 months?

P(x ≤ x₀) = 1 − e^(−x₀/μ)
=EXPON.DIST(18,1/15,TRUE)

Note: Excel takes the rate 1/μ, not the mean. Exponential (time between events) pairs with Poisson (number of events).

🎯 Remember
