🎯Purpose of this task

Your group will generate its own synthetic operational dataset. It represents the daily activity of six sales managers over a 90-day period. In class, you will use this dataset for PivotTable, attendance, sales, expenditure, trend and relationship analysis.

Different numbers are expected. The dataset uses random generation, so every group gets different values. That is how it should be.

🧱Dataset structure

Type these seven column headings in Row 1 of a new Excel sheet, starting at cell A1.

ColHeading (Row 1)Meaning
ADateScheduled activity date
BRecord_IDUnique record number
CRegionNorth, Central, South or East
DManagerManager 1 to Manager 6
EStatusPresent or Absent
FDaily_Promotion_SpendDaily promotional expenditure (RM) when present
GTotal_SalesDaily sales (RM) generated when present
90 days × 6 managers = 540 manager-day records (Rows 2 to 541)

🧮Step-by-step data generation

Enter each formula in Row 2, then fill it down. Tap Copy to copy a formula exactly.

  1. 1

    Generate the date A2

    =DATE(2026,6,1)+INT((ROW()-2)/6)

    Each date repeats six times, once for each manager. Format column A as a date if Excel shows a number.

  2. 2

    Create a unique Record ID B2

    ="S"&TEXT(ROW()-1,"000")

    This gives IDs such as S001, S002, S003 and so on.

  3. 3

    Assign a region randomly C2

    =CHOOSE(RANDBETWEEN(1,4),"North","Central","South","East")

    A manager may appear in different regions on different dates.

  4. 4

    Generate the six managers D2

    =CHOOSE(MOD(ROW()-2,6)+1,"Manager 1","Manager 2","Manager 3","Manager 4","Manager 5","Manager 6")

    The formula cycles through all six managers for every date.

  5. 5

    Generate attendance status E2

    =IF(RAND()<=0.85,"Present","Absent")

    Each manager has about an 85% chance of being present on a scheduled day.

  6. 6

    Generate daily promotional spend F2

    =IF(E2="Present",RANDBETWEEN(500,2000),"")

    If the manager is absent, spend is left blank because no activity took place.

  7. 7

    Generate total sales G2

    =IF(E2="Present",ROUND(MAX(2000,MIN(15000,F2*5+RANDBETWEEN(-1500,1500))),0),"")

    This creates a positive but imperfect relationship between promotion spend and sales, kept between RM2,000 and RM15,000. Absent rows stay blank.

  8. 8

    Fill all formulas down to Row 541

    Select A2:G2, then drag the fill handle down to Row 541. Quicker way: type A2:G541 in the Name Box, press Enter, then press Ctrl + D.

🧊Freeze your generated dataset

Do not skip this step. RAND() and RANDBETWEEN() recalculate every time Excel recalculates, so your values keep changing until you turn the formulas into fixed values.
  1. Select the whole dataset (A1:G541).
  2. Copy it (Ctrl + C).
  3. Right-click → Paste Special → Values (or Ctrl + Alt + V, then V, Enter).
  4. Click any cell in F or G. The formula bar should show a number, not a formula.
  5. Save the workbook.
